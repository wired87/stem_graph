This page is the friendly interface for the official StemCNV-check workflow. Add the files from the DNA chip, press start, and leave the page open. The computer prepares the files, performs the checks, and gives you one ZIP file to download.

For families and parents: Think of StemCNV as a careful sorting machine. It reads measurements from a DNA chip and groups possible chromosome copy-number changes into a report. It does not diagnose a child or replace a doctor, genetic counsellor, or clinical laboratory.
