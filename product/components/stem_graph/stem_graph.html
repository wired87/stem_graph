01

Add the DNA chip folder

Important: If you select even one file, the run uses only your files. Missing files stop the run before Docker starts; official example files are never mixed into researcher data.

You can drop a complete folder. The server checks the names and safely places every file where StemCNV expects it.

Which files must a researcher provide?
  • config.yaml — tells StemCNV which array and reference files to use.
  • sample_table.tsv or sample_table.xlsx — one row per sample, including Sample_ID, Chip_Name, Chip_Pos, Array_Name, and Sex.
  • One green and one red IDAT per sample — matching names ending in _Grn.idat and _Red.idat.
  • All files named in config.yaml — normally BPM, EGT, CSV manifest, PennCNV PFB and GC model, density BED, and gaps BED.

Keep filenames exactly the same as the paths in config.yaml. Duplicate filenames, missing color pairs, and unsafe paths are rejected before Docker starts.
